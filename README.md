\#Лабораторна робота №5: Використання SFML в С++ проєкті

Варіант 7: Моделювання польоту тіла, кинутого під кутом



\##Опис проєкту

Цей проєкт є програмною реалізацією фізичної моделі польоту тіла, кинутого під кутом до горизонту, виконаною мовою C++ з використанням графічної бібліотеки SFML. 



У програмі реалізовано:

\- Обчислення руху тіла під дією гравітації з урахуванням дискретного кроку часу.

\- Відображення траєкторії польоту за допомогою графічних примітивів SFML.

\- Інтерактивне управління параметрами через клавіатуру (зміна початкової швидкості, кута кидання, пауза, скидання).

\- Інформаційну панель із виведенням поточного стану та параметрів системи в реальному часі.



\##Використані технології

\- Мова програмування: C++ (Standard C++17)

\- Графічна бібліотека: SFML (Graphics, Window, System)

\- Менеджер пакетів: vcpkg (у режимі маніфесту "vcpkg.json")

\- Система збирання: CMake

\## Інструкція зі збирання та запуску

1\. Клонуйте репозиторій або відкрийте папку проєкту на комп'ютері.

2\. Переконайтеся, що у вас встановлено Visual Studio (з підтримкою розробки на C++ та CMake) і налаштовано змінну середовища `VCPKG\_ROOT`.

3\. Відкрийте папку проєкту у Visual Studio через меню "File -> Open Folder".

4\. Дочекайтеся завершення конфігурації CMake (автоматично підтягнеться SFML через vcpkg).

5\. Виберіть ціль запуску SFML\_Lab, натисніть Build -> Build All, а потім запустіть проєкт ("F5").



\## Керування у програмі

\- Стрілки Вгору / Вниз — збільшити / зменшити початкову швидкість.

\- Стрілки Вправо / Вліво — збільшити / зменшити кут кидання.

\- Пробіл (Space) — запустити / перезапустити симуляцію.

\- P — поставити на паузу / продовжити.

\- R — скинути до початкового стану.
